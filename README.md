Starshatter Arena — a neon twin-stick arena shooter that runs offline in a desktop browser. Pilot a lone starfighter through 10 escalating waves of geometric hunters, chain kills into a ×8 score combo, grab drops (spread shot, rapid fire, shield, nova bomb, shard magnet), and slay the Void Warden boss to clear the sector — then keep flying in endless mode. Keyboard + mouse or twin touch sticks, synthesized WebAudio sound and music, particles, screen shake, and a seeded attract mode behind the title screen. No libraries, no network, no assets: one canvas, plain ES modules, and `main.ts` hands the game plus its screenshots to the judge.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — or stage a screenshot scene:
# http://localhost:8080/?shot=play&seed=1 (start, play, boss, end)
```
